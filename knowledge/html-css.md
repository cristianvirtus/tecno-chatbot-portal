# HTML y CSS

HTML describe la estructura de una página (títulos, párrafos, botones, formularios). CSS describe la apariencia (colores, espacio, diseño responsive).

## Ideas clave de HTML

Las etiquetas van en árbol: `html > body > main > p`. Un botón se hace con `<button>`, un enlace con `<a href="...">`. El atributo `alt` en imágenes ayuda a accesibilidad.

## Ideas clave de CSS

El navegador aplica estilos por cascada y especificidad. Flexbox y Grid sirven para alinear elementos. Las media queries (`@media (max-width: 640px)`) adaptan el diseño a móvil.

## Responsive

Diseña primero el layout estrecho y luego ensancha. Unidades relativas (`rem`, `%`, `dvh`) se comportan mejor que píxeles fijos en todos los tamaños.

## Ejercicios según tiempo

- 5 min: cambia el color de fondo de un `body` y el tamaño de un `h1`.
- 15 min: arma una tarjeta con título, texto y botón usando Flexbox.
- 30 min: página de dos columnas en escritorio y una columna en móvil.
